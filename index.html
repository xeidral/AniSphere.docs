How it works
Source
⌘

The catalogue is on your disk

Twenty thousand titles indexed locally, so search answers while you type instead of after a request. What is on screen is fetched for the screen, and nothing beyond it.

Getting started

⚡

One request opens the home screen

Four rankings and the spotlight in a single query. The order is kept, so a second visit costs nothing, and every card the page drew is fetched together right after it.

What it asks for

⛓

Everything has something behind it

A ranking falls through to another ranking, a schedule to its stored copy, an episode to the file you saved. Pull the network out and the library is still there.

Downloads and offline

⚑

It says what it sends

Every service is named, with how often it is asked and what is kept. Nothing about what you watch leaves the machine, and there is no analytics endpoint to opt out of.

Privacy

⌗

Boundaries the quality gate enforces

The layers point one way, a command is an adapter and never a decision, and no query may walk a catalogue. ESLint and named Sonar project checks keep that shape visible without turning static rules into tests.

Boundaries

◆

Six sites, raced

Providers are asked at once and the first playable answer wins, with a bound on how long anyone may wait. A source that goes down is routed around, not waited for.
