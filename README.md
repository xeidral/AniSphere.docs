# AniSphere site

The documentation site at <https://xeidral.github.io/anisphere/>.

Built with [VitePress](https://vitepress.dev), the same Vite toolchain the
application itself is built on. Every page under `docs/` is written here: this
is the one place they live.

## Running it

```sh
npm install
npm run dev
```

`npm run build` is what CI runs, and it fails on a link that does not resolve.

## How it is published

`.github/workflows/site.yml` builds on every push to `main` and writes the
result to the root of the `gh-pages` branch.

The publish step preserves a `reports/` directory when one already exists on the
Pages branch, so independently published historical reports are not overwritten.
Current application coverage is generated by the application quality workflow
and evaluated in Sonar; this site build does not produce that report.

## Editing

| To change | Edit |
|---|---|
| The landing page, its hero and cards | `docs/index.md` |
| Any other page | The matching `docs/*.md` |
| What is in the top row and the sidebar | `docs/.vitepress/config.mts` |
| Colours, hero, screenshots, cards | `docs/.vitepress/theme/custom.css` |
